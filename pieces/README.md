# Chess Pieces

For flat black and white chess pieces, you can use:

1. **Wikipedia Commons Chess Pieces** (Public Domain):
   - https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces
   - Simple, flat, monochrome design

2. **lichess.org pieces** (GPL):
   - https://github.com/lichess-org/lila/tree/master/public/piece
   - Clean, modern flat design

3. **chess.com style pieces**:
   - Minimalist flat design

Recommended: Use SVG format for scalability. Download from:
https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces/Standard

Files needed:
- black-king.svg, black-queen.svg, black-rook.svg, black-bishop.svg, black-knight.svg, black-pawn.svg
- white-king.svg, white-queen.svg, white-rook.svg, white-bishop.svg, white-knight.svg, white-pawn.svg
